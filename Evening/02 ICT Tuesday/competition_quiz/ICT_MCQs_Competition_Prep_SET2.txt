Q1. A retail chain uses a system that automatically reorders stock
    when inventory falls below a set level. Which type of
    computer-based system is this?

    A) Expert system
    B) Satellite system
    C) Automated stock management system in the retail industry
    D) Booking system

    Correct Answer: C

---

Q2. Which of the following scenarios describes the use of an expert
    system in medicine?

    A) A doctor uses email to send a patient's report to a specialist
    B) A program analyses symptoms entered by a clinician and
       suggests a ranked list of probable conditions
    C) A hospital printer produces discharge letters automatically
    D) A database stores patient names and contact numbers

    Correct Answer: B

---

Q3. GPS navigation in vehicles relies primarily on which category
    of computer-based systems?

    A) Expert systems
    B) Recognition systems
    C) Satellite systems
    D) Banking applications

    Correct Answer: C

---

    that did NOT exist before computerisation?

    A) Keeping handwritten ledgers of transactions
    B) 24-hour ATM access, real-time fraud detection, and
       instant international transfers
    C) Using physical stamps on paper cheques
    D) Hiring more bank tellers for busy periods

    Correct Answer: B

---

Q5. A border control agency scans passports and matches travellers'
    faces against a database in seconds. This is an application of:

    A) Booking systems
    B) Retail management systems
    C) Expert systems
    D) Recognition systems

    Correct Answer: D

---

Q6. Which of the following is NOT a typical example of ICT use
    in the retail industry?

    A) Barcode scanning at checkout
    B) Loyalty card tracking using customer databases
    C) Diagnosing engine faults in vehicles
    D) Online ordering and delivery tracking

    Correct Answer: C

---

Q7. Online appointment scheduling for a clinic is an example of
    which type of computer-based system?

    A) Expert system
    B) Booking system
    C) Satellite system
    D) Recognition system

    Correct Answer: B

---

Q8. How does ICT specifically improve a school management system

    A) It makes the school building physically larger

    C) It allows faster access to records, automated timetabling,
       and easier communication with parents

Q9. A logistics company tracks delivery trucks in real time and

    A) Expert systems embedded in the trucks
    B) Satellite-based GPS combined with mapping software
